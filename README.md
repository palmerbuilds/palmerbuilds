# Matthew Palmer

I build and configure the software businesses run their quoting and pricing on — and I ship
open-source audio tools when I am not doing that.

Most shops still quote from a spreadsheet and from tribal knowledge. I replace that with a configurator
that knows the catalog, the labor rates, the freight, the discount floors, and the BOM — so the person
writing the quote stops guessing and the number stops moving after it is sent.

---

### What I do

**Quoting and pricing systems**

- CPQ / quote-to-order — product configurators, pricing engines, BOM generation, quote revision control
- Offline-first desktop tooling — Electron, SQLite locally, optional SQL Server sync for multi-seat shops
- Migrating spreadsheet quoting into a structured catalog and rules model, without a year-long ERP project
- Integrations — CRM handoff, PDF/proposal output, ERP line-item export

**Automation and internal tooling**

- Tools that replace a manual process: import / validate / export pipelines, report generation, scheduled jobs
